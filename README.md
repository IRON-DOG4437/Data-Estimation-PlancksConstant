# 🔬 Data Estimation: Curve Fitting Planck's Law

This project demonstrates how to estimate physical constants such as **Planck's constant** and **blackbody temperatures** by applying curve fitting techniques to spectral radiance datasets using Python.

## 📈 Features

- Read and process multiple CSV datasets of spectral radiance
- Apply standard and partial curve fitting techniques
- Estimate temperature and validate accuracy using loss comparison
- Visualize results via Matplotlib graphs

## 🧪 Technologies Used

- Python
- NumPy
- SciPy (curve_fit)
- Matplotlib
- Jupyter Notebook

## 📂 Instructions

1. Clone the repo and place `.csv` files into the `data/` directory
2. Open `EE23B084.ipynb` and update the CSV file paths
3. Run all cells to view plots and final estimations

## 📊 Results

Partial application of Planck’s law improves temperature estimation, consistently achieving ~4000 K across datasets with lower error loss than standard curve fitting.
